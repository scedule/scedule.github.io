Windows

Windows 10/11

Download .zip
  1. Download the zip file.
  2. Extract Schedule-Windows.zip.
  3. Run Schedule.exe inside of the extracted zip.
  4. If SmartScreen appears, click "More Info" then "Run Anyway".
  5. To add it to the Start Menu for easy access:
    • Right-click Schedule.exe and select Create shortcut.
    • Press Windows + R, type %APPDATA%\Microsoft\Windows\Start Menu\Programs, and press Enter.
    • Drag your shortcut into this folder. Optionally, create a subfolder like "Schedule" for organization.
    • You can rename the shortcut and change its icon by right-clicking Properties then Change Icon.
    • After adding the shortcut, open the Start Menu and your app should appear. If not, restart Windows or log out and back in.
  6. Now you can run Schedule.exe directly from the Start Menu whenever you want.

Linux

Most mainstream distros.

Download .AppImage
  1. Download the .AppImage file.
  2. Run ./Scedule.AppImage in the folder you downloaded it in.
  3. If you wish for it to be a easily accesible application you can move it into /usr/bin and rename it to Scedule.
